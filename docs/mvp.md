# MVP

つい触りたくなるかを確かめるための、最初の一本。

## 動機

海の街に住んでいて、潰された蟹をよく見た。それをゲームにしたい。

## 遊び

クロスザロード系のクソアホゲー。ニワトリやカニ、カブトムシ、甲殻類や虫が、車の通る道路を渡る。

- 画角は真上から見下ろす形より、蟹の少し上。蟹視点ではない。車のフロントの下くらいから、奥へ向かってくるタイヤを避ける
- 避けるのはタイヤ。車体の下はくぐっても問題ない
- 潰れた場所に亡骸が残る
- アイテムや難易度でゲーム性を上げるのは、この確認のあと
- 癖になって、つい触りたくなるものを目指す

## 操作

- PC は左右キーで移動
- スマホはタッチ、または画面上のボタン。ボタンは HTML in Canvas で置く

## この MVP でやること

- 道路は 1 本。横幅（渡る距離）は `src/game/constants.ts` の `ROAD.width`（24）
- 手前の歩道から出発し、向こう側の歩道（黄色い線）に着いたらクリア。クリア画面からもう一回遊べる
- 開始時点で車はすでに流れている（交通を 20 秒空回ししてから始める）
- 道路は 6 車線。車線ごとの向き（手前向き / 奥向き）・基本速度（10〜18）・平均出現間隔（0.8〜2.0 秒）・車種の割合は、毎回のプレイ開始時にランダムに決める。向きは必ず両方混ざる
- 車種は 3 つ。普通の車、突然来る速い車（2.4 倍）、遅くて長いトラック（0.45 倍）。当たり判定はどれもタイヤだけで、トラックの下は左右の車輪の間にいれば長くくぐれる。同じ車線では追い越さず、前の車に詰まる
- 押しっぱなしではまず渡れない（シード付き試算で 100 回中 100 回轢かれる）。0.6 秒先だけ見て隙間を待つ素朴な戦略は 100 回中 74 回クリアできた
- ゲームオーバー / クリア画面の後ろでも車は流れ続ける。蟹（亡骸）はその場に残る
- やられ演出: ぺしゃんこ（一瞬で潰れて横に広がる）、カニ汁の粒が飛び散る、画面いっぱいのオレンジのしぶきと垂れ（ホラー映画風だけどふざけた色）、「ぷしゃーっ!!」の文字、スローモーション（1 秒間 0.12 倍）、画面の揺れ。計算は `src/game/effects.ts` の純粋関数
- 亡骸は次のプレイ以降も残り、同じ場所に落ちたものは積み重なる
- 蟹のモデルは `src/game/models/crab.tsx` の `CRAB_MODELS` で差し替える。今は箱の仮置き（生きている蟹 / 潰れた蟹）。glTF にするときは drei の `useGLTF` で同じ props のコンポーネントを作って入れ替える
- 左右に移動できる
- タイヤに当たったら終わり
- 潰れた跡が残る
- 蟹と車は箱や円柱で仮置きする。モデルは後回し
- カメラは正面視点の 1 つに絞り、蟹の左右移動に追従させる。補間せず x をそのまま合わせ、止まったときに揺れ戻さない（奥から来るタイヤの位置が錯覚で見誤りやすいため）。道路の向きの切り替えは後回し

## 技術

- Vite + React + TypeScript で始める。SSR は不要なので Next.js は見送り。Vite の静的出力は Electron に載せやすい
- バックエンドが必要になれば、別 API として足す
- 描画は react-three-fiber + drei。奥行きがあるので Pixi より Three.js。まだ依存には入っていない
- デスクトップは Electron を第一候補にする。HTML in Canvas は実験中の Chrome の機能なので、Mac の Tauri（WebKit）では動かない可能性が高い
